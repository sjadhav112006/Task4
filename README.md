# Task 4 - Sales Performance Dashboard

## Objective
Designed an interactive sales dashboard for business stakeholders using Power BI.

## Dataset
Financial Sample dataset from Kaggle.

## Dashboard Features
- KPI Cards: Gross Sales, Profit, Units Sold
- Monthly Sales & Profit Trend (Line Chart)
- Sales by Segment (Bar Chart)
- Sales by Country (Donut Chart)
- Year Slicer for interactivity

## Tools Used
Power BI Desktop
